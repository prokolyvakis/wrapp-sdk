# Declaration baseline

wrapp-sdk.api.md is the public API surface reachable from the root entry point, generated by
[API Extractor](https://api-extractor.com/) from the emitted declarations. It is a review
trigger, not a semantic-version oracle. Only root package exports are supported; no deep
imports are promised.

Run `npm run check:api` to compare; after intentional public changes, review compatibility
and run `npm run api:update`. Do not refresh the baseline merely to make CI green. The first
baseline is pre-release 0.0.0, not evidence that a previously published stable version existed.
